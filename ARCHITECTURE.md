# pragmatic-server — Architecture Index

> Navigational map for orientation. Read this before re-exploring. **Maintenance rule:** when a change moves or renames a seam below, update this file in the same commit. Line numbers drift — treat them as "near here", trust the symbol name.

**Package:** `@pragmatic-tech-ai/pragmatic-server` — Layer **L4** headless server. Exposes the TODL engine (+ connectors + identity) to remote clients over `pragmatic-protocol` (JSON-RPC 2.0 over WebSocket). Consumes TODL + todl-runtime + pragmatic-protocol + todl-identity + todl-platform-node as built `dist` via `file:` sibling deps.

**Vision context (read these memories):** the server is two **tenant types** — a *development* center (collaborative edit of ONE active solution; the surface SP3/Cypher shipped against) and a *runtime* graph provider (compiled application = package set + connectors). See memory `project_server_dual_purpose` and `project_server_architecture`. The dev-vs-runtime tenant **type** now exists in code as `TenantPurpose` (`src/tenancy/tenant-purpose.ts`: `Development` / `Runtime`; `PragmaticServer.Purpose()`); the runtime data-op surface is described under "Runtime data ops" below.

## Layering & composition

- Per-tenant **`PragmaticServer`** builds a `LazyCompositionRoot(HostKinds.Server)` — lazy domain modules (solution-services, language-service: Dormant→Active on first `Resolve`) + eager infra (storage, prompt, package source/store, connectors). `src/pragmatic-server.ts`.
- Engine-never-imports-server holds: the server composes down into TODL; TODL has no server symbol.

## Entry points

- **Programmatic:** `PragmaticServer` (`src/pragmatic-server.ts`) — `Start` / `OpenSolution(dir)` / `Manager()` / `LanguageService()` / `DevEngine()` / `DevScopes()` / `DevCypher()` / `Connectors()` / `Dispose`.
- **Process:** `bin` entry via `ServerBootstrap` + `ServerConfigLoader` (`src/config/`) — env+file config, fail-closed; SIGTERM graceful shutdown.
- **Host:** `PragmaticServerHost` (`src/host/pragmatic-server-host.ts`) — one server over a `ws` `WebSocketServer({ noServer: true })`; `StartAsync` / `DisposeAsync`. WorkerHost variant for multi-tenant workers.

## HTTP / transport surface (`src/host/pragmatic-server-host.ts`)

- `createServer()`/`httpsCreateServer` + `WebSocketServer` (~:213); upgrades via `wss.handleUpgrade` (~:430). **WebSocket is the primary surface.**
- HTTP router `Request(req,res)` (~:482):
  - `/healthz` + `/readyz` — `HealthEndpoint` (`src/host/health-endpoint.ts`), unauthenticated.
  - `/auth/login`, `/auth/oidc/begin`, `/auth/oidc/callback`, `/auth/machine` — `AuthHttpEndpoint` (`src/host/auth-http-endpoint.ts`), deny-by-default token issuance.
  - everything else → 404.
- **No static/SPA/asset serving today** (relevant: runtime-tenant same-origin frontend is a future cycle).

## Domain binding: solution → graph (`src/pragmatic-server.ts`)

- `Manager()` (:202) → `root.Resolve(SolutionManagerService.Key)`. Holds **ONE active solution** (engine side; see TODL index). `OpenSolution` (:212) delegates to the manager.
- The dev tenant's graph is the embedded engine (`DevEngine()`, see "Dev graph engine"); the runtime tenant composes from an application's *package set* (`GraphForPragmaticApp`) or the loaded environment graph.

## Cypher query path (`src/host/cypher/`)

- **Dev `cypher/query` / `cypher/models`** run on the dev graph engine (`DevCypherQuery`, see "Dev graph engine"); the handler gets it as `IDevCypherQuery` (its 6th Attach parameter, `devCypher`, from `DevelopmentAttachArgs`). The legacy dev graph caches (`TenantGraphCache`, `ModelShardCache`, `ModelShardGraph`, `TenantGraphComposition`) are gone. The runtime branches (bound app, environment graph) still execute TODL `Cypher.CypherEngine.OverQuery` over an `IGraphQuery`.
- **Read endpoint guards:** `cypher/query` parses once and rejects a well-formed write (names `cypher/execute`) and, when paged, a tail SKIP/LIMIT. Runtime cursors also fingerprint the reachable data (`paging/graph-data-digest.ts`), since runtime graphs re-pull per request.
- **Cells:** `cypher-result-mapper.ts` decodes engine cells with `Cypher.CypherCellCodec` (node = `{ "$node": … }`, reserved-key maps escaped as `{ "$map": … }`) — never by shape.
- **Writes (`cypher/execute`, dev):** run on the dev graph engine (`DevCypherExecute`, see "Dev graph engine"). The legacy draft writer (`DevCypherExecutor`, `DevModelWriter`, `AuthorizingCypherWriter`, `dev-write-security.ts`, `DevWriteTargetSource`, `ReflectedView`) is gone; `write-lock.ts` (`IWriteLock`, `InProcessWriteLock`; `RedisWriteLock` from `RedisTenantOwnership` in a cluster, via `PragmaticServerOptions.writeLock`) and `cypher-execute-result-mapper.ts` (`Applied(status, revision, page, engine stats)` / `Refused(status, revision, reason)`, over the graph engine's `CypherWriteStatsDto`) remain. Secured runtime graphs forward `Materialize` (read-your-writes).
- **Push-down (runtime):** a runtime read passes `{ text, parameters }` to `GraphForPragmaticApp`, which pushes `Cypher.CypherPushDown` ∧ the access-policy push-down (only with no record shares) into `ConnectorPrefetch` source queries.
- **Handler:** `ServerConnectionHandler` registers `CypherProtocol.Query` under `guarded` (rate-limit→authorize→handler); `cypher-param-converter.ts` (wire params→engine, `Object.create(null)` anti-`__proto__`), `cypher-result-mapper.ts` (engine PascalCase→wire camelCase). Error map: syntax/semantic→InvalidParams, `CypherTimeout`→ -32030 (`DevCypherQuery.TimeoutCode`, re-exported as `ServerConnectionHandler.CypherTimeoutCode`). Limits from `CypherLimits` config.

## Dev graph engine (`src/host/engine/`)

Plan M1.4 moves the dev-tenant graph onto an embedded pragmatic-graph engine (`@pragmatic-tech-ai/graph`, `file:../pragmatic-graph`). Inputs come from SAVED `.todl` files only, never the language service's unsaved buffers (`DidChange` text is a live buffer).

- **`SavedMemberReader`** (`saved-member-reader.ts`) - per member: `TodlSourceCollector.Collect(storage)` + `ResolveBasesFor(storage)` -> `SavedMember { Storage, Sources, Bases, OriginOf, Models }`; `Models` = the `model` containers the member's own sources declare (compile provenance). `NamespaceOf(modelId, solutionName)` = id prefix, else solution name. `DeclaredModelCache` keeps each storage's declared models for the source hash they were compiled from, so an unchanged member is not recompiled; the engine host shares ONE reader between the snapshot source and the workspace (both constructors take an optional reader).
- **`DevSnapshotSource.Current()`** (`dev-snapshot-source.ts`) - every member with a model compiled from its saved sources (absolute uris) by TODL `SavedModelCompiler` (one package per model id, so seed `Owner` = model id; instances outside every model -> the solution package), described by `SnapshotDescriber` with `DefaultConnector: TodlNames.FileConnector`. `Description.Version` is the content digest `GraphEngine.Upgrade` compares. Base nodes compiled from an in-solution member that is itself compiled here are stripped (`OriginOf` `OpenProject`), so nothing is declared twice. `CompileDiagnostics` carries the compile's diagnostics (an error = the saved sources do not compile).
- **`ServerModelWorkspace`** (`server-model-workspace.ts`) - TODL `ITodlModelWorkspace` for `TodlFileConnector`: `OpenDraft(modelId)` finds the member whose saved sources declare the model (`OwningMember`, the only copy), drafts over its sources (storage-relative uris), `SourceHash` = `TodlSourceCollector.SourceHash`. Solution name / undeclared id -> undefined (not editable). Each `WriteFile`/`DeleteFile` is a per-file compare-and-swap (storage must hold the opening text or this session's own last write, else it refuses with `EngineBridgeError` `Stale` -> the connector fails the commit Stale, restores what it wrote and does not count the refused write as unrestored: two models sharing a file cannot lose an edit), then `DidChange(absoluteUri, text)` / `DidDelete(absoluteUri)` + `WhenIdle()`; before its first write each session checks the installed write fence (`WriteFenceSlot`, ctor's optional fifth parameter; a lost fence refuses the write untouched as `Stale`, checked once so a restore is never refused); a refresh failure goes to `IDevWriteDiagnostics.RefreshFailed` (default `ConsoleDevWriteDiagnostics`, error names only; the host passes its own) and never fails the write. `IDevLanguageService` (`dev-language-service.ts`) is the language-service slice the engine side reads and writes through. Absolute uris: `TodlSourceCollector.AbsoluteUri`.
- `IDevSolution` (`dev-solution.ts`) is the solution slice it reads (`Name`, `Members.ToArray()`); TODL `Solution` satisfies it.
- **`DevGraphEngineHost`** (`dev-graph-engine-host.ts`) implements `IDevGraphEngine { Engine(); Repository(); Description(); Snapshot(); WhenUpgraded(); InstallWriteFence(fence): IDisposable; Changed: ISignal<void> }` + `IDisposable` (`Snapshot()` = the whole `DevSnapshot` the engine runs in one read, incl. its `CellMapper`: TODL `EngineCellMapper` over the same compiled metadata). `PragmaticServer.DevEngine()` memoizes one (`devEngine ??=`; throws once the server is disposing; `DoDispose` disposes the scope source and then it, after the connectors host and identity flow store, just before draining the language service); `ServerConnectionHandler.DevelopmentAttachArgs` hands it (with `devGraphService`) to every dev-tenant `Attach` in BOTH `PragmaticServerHost` and `WorkerHost` (the handler's last ctor/Attach parameter `devEngine`). Opens on first use: `GraphEngine.Open({ Description, Storage: Memory, Connectors: [TodlFileConnector(ServerModelWorkspace)] })`, no solution -> the empty description. Upgrade: `GraphChanged` only (re)arms a `UpgradeDebounceMs = 150` debounce (`IUpgradeTimer`; never works inside the language-service queue or a commit's refresh); one drain loop then recompiles (`DevSnapshotSource.Current()`) and calls `engine.Upgrade` only when `Version` differs, changes arriving meanwhile coalescing into one more pass. The connector is wrapped by `EngineWriteTracker`, which counts the engine's own connector transactions (Begin -> Commit/Revert, plus a post-commit compensating Revert): the drain waits until none is in flight and re-reads when one began while it read, so a multi-file commit half on disk is never applied (an upgrade mid-commit would also fail that commit, ruling R77); the one remaining window is a commit that begins while `Upgrade` runs, which fails with a retry-safe ConflictError. `DevSnapshotSource` returns its previous snapshot without recompiling when the solution, every member's source hash and its bases fingerprint (`SavedMember.BasesHash`: content of the resolved bases + origins, so freshly rebuilt sibling bases still match) are unchanged; `DeclaredModelCache` never caches a compile with errors. A throwing `Changed` subscriber is reported (`ChangedHandlerFailed`) and never stalls later upgrades. A throw or compile error (`DevSnapshotCompileError`) is reported to `IDevEngineDiagnostics` and not applied: the engine keeps its previous version, the next change retries. `Changed` is raised after each applied upgrade. `WhenUpgraded()` resolves once every upgrade already asked for has finished: a pending debounce is cut short (its drain pass runs now) and the running drain is awaited; `DevCypherExecute` calls it after a commit (the commit's file writes raised `GraphChanged` before each `WhenIdle` it awaited). There is no forced re-read (the legacy writer's `Synchronize()` is gone with it). The ctor's optional fifth parameter is the workspace's `IDevWriteDiagnostics`.
- **`DevAccessScopeSource`** (`dev-access-scope-source.ts`) - the ONE place dev graph access is decided: `ScopeFor(ctx): Promise<IDevScope { Scope: AccessScope; Placement(modelId); Digest }>`; endpoints pass `Scope` to the engine and never filter or mask themselves. Scope = TODL `PolicyScopeCompiler.FromRepository(host repo, description).Compile(PrincipalFacts, Allow)` AND (identity configured) `DepthScopeCompiler.Compile(TenantReadAuthorization.EvaluatorForContext(ctx), principal, description)`, combined deny-wins by `AccessScopeConjunction` (same-key Rows ANDed, Writes ANDed per op, Hidden / HiddenExact and ReadOnly / ReadOnlyExact (per op) unioned key by key, a Deny default the other scope's entries would override materialized as `Not(ConceptIs concept)` ANDed onto that concept, never a plain False that would reach its subconcepts). Policy entries (and policy Hidden) keep engine inheritance. No identity: policy Rows only, Default Allow, no write rules (today's open dev writes). Cached per `Digest` = JSON of (`ConnectorPrincipalDigest`, tenant, sha256 of the sorted claims, engine `SchemaVersion`, security generation); `TenantReadAuthorization.Invalidated` (`ISignal<string>`, raised by `Invalidate`) bumps the generation and drops the cache, host `Changed` drops it. Every compiled scope is opened once on the engine (`BeginRead`, its ScopeValidator) before it is handed out; compiler diagnostics go to `IDevScopeDiagnostics` (default `LoggerDevScopeDiagnostics` over `ILogger`; once per message until the cache drops). Digest coverage: the exact member sets are derived only from the evaluator (tenant + security generation), the principal (principal digest + claims hash) and the schema version, all already in the Digest. Failures are `DevAccessScopeError` (`DevAccessScopeErrorCode`). `Placement(modelId)` = `TodlNodePlacement(modelId, NamespaceOf(modelId, solution))` + the depth create defaults (`IPlacementDefaults`) as `INodePlace.Defaults`.
- **Production wiring:** `PragmaticServer.DevScopes()` memoizes one `DevAccessScopeSource(DevEngine(), identity ? ReadAuthorization() : undefined, identity configured, active solution name, LoggerDevScopeDiagnostics(options.logger ?? NullLogger))` (a failed build is evicted and retried); `PragmaticServerOptions.logger` is the host's logger, handed down by `TenantRegistry` (both hosts pass `options.logger`). Disposed with the server, before the engine.
- **`DevCypherQuery`** (`dev-cypher-query.ts`) - dev `cypher/query` + `cypher/models` on the engine (`PragmaticServer.DevCypher()`, memoized). `Run(ctx, { Source; Parameters (converted once by the handler); CanonicalParameters; ModelId?; Page { Params, Limits, RowCap }; TimeoutMs; MaxVarLength })`: scope = the caller's `IDevScope.Scope`; a `ModelId` must be one of `Models()` (else InvalidParams "model not found", identical for every unknown id) and ANDs `Or(ConceptIs todl.Term, OwnerIs(modelId))` into the `todl.Element` rows entry (`AccessScopeConjunction`, deny-wins; cached per scope object), so the model filter reaches every concept but the terms, which the caller scope alone governs (ruling T6-b: term refs survive a model scope). Executes `Cypher.CypherEngine(engine, { MaxVarLength }).Execute(scope, source, { Parameters, Limits: { Skip, RowCap, Cancel: Deadline.After(TimeoutMs) } })` -> `DevSnapshot.CellMapper.MapResult(dto, reader)` (one reader per attempt under the same scope answers `HiddenMembers`; its open failure is handled like an Execute error) -> `CypherResultMapper.ToWire`. Cursor fingerprint = `cypher`, text, canonical params, engine `SchemaVersion`, latest commit (an `AccessScope.System` reader's `SnapshotCommit`), the scope `Digest` (always, so a cursor is stale for another principal) and, model-scoped, `model` + the model id. The state is read before and after the run; a run that saw an upgrade or commit is repeated (`MaxAttempts` 5); a continuation that never settles is CursorStale, a first page `DevCypherQueryError` `Unsettled`. Engine `CypherErrorCode.Syntax` / `Semantic` / `IntegerOverflow` -> InvalidParams, `Timeout` -> -32030. `Models()` = `DevSnapshot.Models`: the model ids the saved compile accepted (one package each, empty models included), without the solution package. The endpoint never filters or masks. Without an attached `IDevCypherQuery` both endpoints report InvalidParams "dev cypher not available".
- **Hidden members on the wire:** TODL `EngineCellMapper.MapResult(dto, hidden)` (`hidden` required; an unscoped caller passes a System reader) leaves a hidden member out of a node cell's `fields` and `refs`, like the legacy masked mirror: a property field absent from the engine cell's properties (the engine's `ReadNode` emits every visible property, null when unset, and omits hidden ones), and a relationship-held field (concept/aspect typed, many-valued taxonomy) that the scoped reader's `HiddenMembers(concept)` reports (a node cell cannot tell a hidden relationship from an empty one).
- **`DevCypherExecute`** (`dev-cypher-execute.ts`) - dev `cypher/execute` on the engine (`PragmaticServer.ExecuteCypher` -> `DevExecute()`, memoized: `DevCypherExecute(DevEngine(), DevScopes(), language-service GraphRevision, options.writeLock ?? InProcessWriteLock, LoggerDevExecuteDiagnostics(options.logger ?? NullLogger))`; runtime tenants InvalidRequest). `Run(ctx, modelId, DevCypherRequest { cypher, parameters, expectedRevision?, timeoutMs, maxVarLength })`: `modelId` must be one of `DevSnapshot.Models` (the `cypher/models` list), else InvalidParams "model not found". Then an in-process `AsyncMutex` and the tenant write lease (busy -> Conflict with the lock's message), installed for the whole write as the workspace's write fence (`IDevGraphEngine.InstallWriteFence`, `WriteFenceSlot`; one fence is safe because dev executes are serialized). One `Deadline.After(timeoutMs)` covers every attempt. Each attempt (at most `MaxAttempts` 2) first re-checks `expectedRevision` against `GraphRevision` (else Conflict "graph revision has advanced") and `lease.Held()` (else Conflict "the tenant write lease was lost before the write could persist"); each draft session checks the fence again right before its first file write (ruling T7-c, legacy's "right before persist" position) and refuses a lost one as `EngineBridgeError` `Stale`, which `DevCypherExecute` reports with the lease-lost reason: nothing persists once the lease is lost. Writes are confined to `modelId` (ruling T7-b, `ModelWriteScopes`): the caller's scope AND `Or(ConceptIs todl.Term, OwnerIs(modelId))` on the `todl.Element` Create / Update / Delete rules (`AccessScopeConjunction`, deny-wins, cached per scope object and model); reads during execute stay tenant-wide, and terms keep the caller's rules (their writes stay NotEditable -> Invalid). Executes `Cypher.CypherEngine(engine, { MaxVarLength }).Execute(confined scope, cypher, { Parameters, Limits: { Cancel: deadline }, Placement: scope.Placement(modelId) })` after `host.WhenUpgraded()` and with the engine and snapshot at one version; the engine's `.todl` file connector writes the owning member's saved files (a new instance lands in the file that holds the model's instances: the legacy writer's second `model X` block in a new file is gone). Status mapping (`DevWriteFailure.KindOf`): `CypherWriteErrorCode.Conflict` / `ConflictError` is retried once (a commit racing an upgrade fails retry-safe, R77), then Conflict; a `ConnectorError` caused by `EngineBridgeError` `Stale` is Conflict, both "model sources changed during the write" (a fence refusal: the lease-lost reason); `Denied` / `AccessError` (MemberReadOnly, HiddenMember: ruling T5-d) -> Denied; `Invalid`, `NodeHasRelationships`, `EngineBridgeError` `NotEditable` / `ForeignId` / `UnsupportedValue` -> Invalid; any other connector failure (`PersistFailed`, an AggregateError from a failed revert) -> Failed. Refusals carry fixed reasons, no counts/rows, and the revision read after the connector restored what it wrote (a restore is told to the language service, so a following `expectedRevision` write matches). A write that commits nothing (`result.Commit` undefined) is Applied with zero counts and the unchanged revision; a committed one awaits `WhenUpgraded()` and returns `GraphRevision`. A failure after the commit (reading the rows, the upgrade wait) is reported to `IDevExecuteDiagnostics.AfterCommitFailed` (error name only) and never fails the applied write: Applied, rows best-effort. RETURN rows: `DevSnapshot.CellMapper.MapResult(dto, reader under the same scope)` -> `CypherResultMapper.ToWire`. Engine Syntax / Semantic / IntegerOverflow -> InvalidParams, Timeout -> -32030 (`DevCypherQuery.WireError`); the handler's `RunCypherExecute` no longer maps errors itself. Accepted engine strictness: writes see only visible nodes (a SET on a hidden node matches nothing: Applied, zero counts); a DETACH unlink checks the other endpoint's Update rule; a create-only member is settable on create only; an edge is removed through its member (`REMOVE a.rel`), a relationship variable is no write target.
- **`DevModelView`** (`dev-model-view.ts`) - dev `model/view` + `model/resources` visibility on the engine (`PragmaticServer.DevModelView()`, memoized, disposed before the scope source; the handler gets it as `IDevModelView`, its last Attach parameter `devModelView`, from `DevelopmentAttachArgs`; a Development handler without one reports InvalidParams "dev model view not available"; runtime tenants keep `ModelReadFilter`). `Page(ctx, memberId, { Params, Limits })` / `Hidden(ctx, nodeId)`. STRUCTURE (nodes, attrs, edges, provenance) comes from the language service as before, unsaved buffers included; instance VISIBILITY and attribute MASKING come from the caller's `IDevScope` on the saved engine snapshot, mapped onto the structure by `EngineModelGate` (it decides nothing itself): an instance (typed, `isClass` false) is kept iff `GraphReader.ScanNodes('todl.Element')` under the scope returns its id with the same engine concept (`ConceptOf`); untyped nodes (schema, models, policies) and typed class nodes (classes, taxonomy terms: TODL types a term with its taxonomy's represented concept and marks it `isClass`) are always kept; a kept typed node's fields are masked by `reader.HiddenMembers(concept)` (HiddenExact included), a typed non-instance whose concept the engine lacks is fully masked. Paging, edge dropping (invisible target, invisible via node, hidden via member by its localId) and provenance stripping are the shared `ModelProjection` (`model-read-filter.ts`; `ModelMemberBuilder` now takes an `IMemberReadGate`, `FieldReadMaskGate` for the runtime mask). Unsaved buffers (ruling T8-a, fail-closed): an instance the saved snapshot lacks, or whose concept the buffer changed, is hidden unless the scope restricts no read (`AccessScope.ReadsUnrestricted`: no identity and no policy), where every instance is visible as before and no scan runs. Cursor fingerprint = `modelView`, member id, `GraphRevision`, engine `SchemaVersion`, engine commit, scope `Digest`. The visible-id set is cached per scope digest for the latest (schema version, commit) and dropped on host `Changed`; a read that saw an upgrade is repeated (`MaxAttempts` 5, then `DevModelViewError` `Unsettled`). The access-depth filter now applies to model/view (audit defect 3: the legacy `ModelReadFilter` applied the TODL policies only). `model/resources` of a hidden instance is `[]`.
- **Dev graph behaviour changes (vs the legacy TenantGraphCache / ModelShardCache):** (1) tenant-wide `MATCH (n)` (and a model-scoped one) also returns the taxonomy terms as `todl.Term` nodes, which the legacy graph never exposed as Cypher nodes - a deliberate dev superset (ruling T6-c): terms are real engine nodes, and hiding them would drop taxonomy refs, since the engine drops links to invisible targets; (2) cursors fingerprint the engine state, not `GraphRevision`: an unsaved edit no longer stales a dev cursor, a save that upgrades the engine does; (3) every dev cursor carries the principal's scope digest; (4) `cypher/models` lists the compiled models from SAVED sources. (5) `cypher/execute` (Task 7): every write to a node created in the same query is judged at its create (ruling T7-a: Create rules on the end-of-batch values, `ReadOnly.Create`), so `CREATE (w) SET w.f = v` ends as `CREATE (w {f: v})`, which legacy allowed; a member read-only on update only is therefore writable there (legacy: Denied), while one read-only on create too, or a concept whose Create is denied, stays Denied; (6) a write under `modelId` to another model's instance is Denied (legacy: Invalid, the draft froze it; ruling T7-b), and the same instance is writable under its own model id; (7) a failed multi-file write tells the language service of each written and each restored file (legacy notified only after a full persist), so `GraphRevision` moves and the Failed result carries the post-restore revision. (8) `model/view` (Task 8): access depth and field security now apply (audit defect 3); an instance only in an unsaved buffer is hidden under a restricted scope (legacy: policy-evaluated on the buffer values); a saved instance is judged on its SAVED values, not the buffer's; taxonomy terms and classes are always kept (legacy ran these typed class nodes through their type's TODL read policy); a cursor is also stale after an engine upgrade or commit and for another principal.
- **`DepthScopeCompiler`** (`depth-scope-compiler.ts`) - reproduces today's exact-concept `AccessDepthInstanceFilter` / write gate: every described concept K gets Rows and Create/Update/Delete entries guarded `Or(Not(ConceptIs K), rule)` (R93), so a rule never reaches K's subconcepts. Rule = K's own level: None False, Organization True, User `In(owner, [id, ...teams])`, BusinessUnit / BusinessUnitAndChildren `In(bu, evaluator.ReachOf(principal) [+descendants])` with OwnershipResolver's root fallback for an unset/empty/unknown unit VALUE; a missing or non-String owner / BU field compiles to False with a diagnostic. Ungoverned concepts are None (denied); a tenant with no security model (DenyAll) denies every instance, while `todl.Term` stays readable (today's schema-level terms) and is never writable. Field security is exact-concept like today's mask (R94): unreadable secured member -> `HiddenExact`; readable but not create-writable -> `ReadOnlyExact.Create`, not update-writable -> `ReadOnlyExact.Update`, so a member secured on a parent is never hidden / read-only on a subconcept that does not secure it. Declared behaviour change: write-only members (hidden but writable) are not supported, writing a hidden member is refused (`HiddenMember`). `EngineSchemaCatalog` (`engine-schema-catalog.ts`) reads concepts, ancestors, applicable keys and effective members (with property types) off the description so every emitted name is valid. `PrincipalFacts` (`principal-facts.ts`) adapts `Principal` to TODL `IPrincipalFacts` (`groups` -> Groups, else a claim).

## Runtime data ops (`TenantPurpose.Runtime`; `src/host/sharing/`, `src/host/apps/`)

- **Applications:** `PragmaticAppsRegistry` (`src/host/apps/`) lists/opens an application (manifest = package set); a connection binds one app (`boundApp`) via `application/open`. Data ops require a bound app, else "no application selected".
- **Per-app `PragmaticServer` methods** (Runtime only): `GraphForPragmaticApp`, `WriteForPragmaticApp` (`data/write`), `ShareForPragmaticApp` / `UnshareForPragmaticApp` / `ListSharesForPragmaticApp` (`data/share`, `data/unshare`, `data/shares/list`; SP-5 record sharing), `AssignForPragmaticApp` (`data/assign`; SP-5b record assign). `AppShareStore(name)` is the per-app share persistence.
- **Services** (`src/host/sharing/`): `ShareService` (grant/revoke/list), `ShareStore` + `ShareGrantIndex` (per-principal grants keyed by concept/record; `AllowsRecord`), `AssignService` (changes owner / owning-BU columns under the **Assign** right via role OR record share, bypassing the Update gate; maps `AssignOutcome` from the identity engine to `AssignStatus`; empty mapped fields -> `Invalid`, adapter fault -> `Denied` "write failed", key conflict -> `Denied` "write conflict"), plus `ShareWidening*` filters/authorizers that widen read/write for shared records.
- **Provider threading:** `ServerConnectionHandler.RuntimeAttachArgs(server)` returns `{ applications, appGraphProvider, appWriteProvider, shareProvider, unshareProvider, listSharesProvider, assignProvider }` (all `undefined` for a Development server); both Attach sites (`PragmaticServerHost` and `WorkerHost`) spread it into `ServerConnectionHandler.Attach`, which stores each provider and forwards the call with the bound app name.
- **Policy:** `PolicyGate` maps `data/write`, `data/share`, `data/unshare`, `data/assign` to `writeTenant` (Write/Tenant); the finer Assign/Share rights are enforced inside the services, not the gate.

## Connectors (`src/host/` + phase-6 wiring)

- `PragmaticServer.Connectors()` (:226) — reaches the first member with `.Storage` (same solution-view seam). In-process `ConnectorRuntime` + `ConnectorsHost`; `ConnectorService` + handlers over `ConnectorProtocol`. Per-tenant `ConnectorsPolicy` (allowlist / catalog-only fail-closed / provider-override) via `PolicyConnectionResolver`. Runtime app graphs prefetch connector rows per request (`ConnectorPrefetch`), with query/policy filters pushed down.

## Identity / RBAC / authorization

- **`PolicyGate`** — deny-by-default `BuildTable` mapping protocol method → required `{ Action, ResourceKind }` (e.g. `CypherProtocol.Query.method → Read/Tenant` from `Tenant.Id`). `src/host/policy-gate.ts`.
- RBAC instance filtering uses `AccessContext` (from todl-identity) per request, applied in the graph cache (deny-wins) — not inside the engine.
- `guarded(...)` pipeline in `ServerConnectionHandler` wraps every method: rate-limit → authorize (PolicyGate) → handler.

## Config / provisioning (`src/config/`)

- `ServerConfigLoader` (env+file, fail-closed), `FileTenantProvisioning`, `tenant-provisioning-factory.ts` (source selection), `CypherLimits` (`cypherRowCap`/`cypherTimeoutMs`/`cypherMaxVarLength`) → `ServerBootstrap.CypherLimitsOf` → `cypherLimits` option → both host variants → `Attach`.
